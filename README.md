# دليل النشر: GitHub Pages + Google Sheets

## 1) تجهيز Google Sheets (حفظ النتائج)
1. أنشئ جدول Google جديداً (Google Sheet).
2. من القائمة: **الإضافات ← Apps Script**، واحذف الكود الموجود والصق محتوى `Code.gs`.
3. غيّر قيمة `PIN` في أول الملف إلى رمز المدرب الذي تريده.
4. اضغط **نشر ← نشر جديد ← نوع: تطبيق ويب**:
   - تنفيذ باسم: **أنا**
   - من لديه حق الوصول: **أي شخص**
5. وافق على الصلاحيات، ثم انسخ **رابط تطبيق الويب** (ينتهي بـ `/exec`).
6. افتح `index.html` وضع الرابط في السطر `const SHEET_URL='';` بين علامتي الاقتباس.

عند تعديل `Code.gs` لاحقاً: **نشر ← إدارة عمليات النشر ← تعديل ← إصدار جديد**.

## 2) الرفع على GitHub
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع الملف `index.html` فقط (أو الملفات الثلاثة إن أردت).
3. من **Settings ← Pages**: اختر **Deploy from a branch**، الفرع `main`، المجلد `/ (root)`.
4. بعد دقائق يظهر رابط الموقع: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## 3) ملاحظات مهمة
- النتائج تُكتب في ورقة `results` داخل الجدول، والإشعارات في ورقة `notes`. زر Export في لوحة المدرب ينتج ملف Excel كما كان.
- رمز المدرب لم يعد داخل `index.html`؛ يُتحقق منه على الخادم في Apps Script.
- **لا تكتب مفتاح OpenRouter في أي ملف.** يدخله المستخدم من ⚙️ في الموقع ويُحفظ في متصفحه فقط.
- رابط Apps Script يقبل الكتابة من أي شخص يعرفه، فمن الأفضل ألا تنشره خارج الموقع. أما قراءة النتائج فمحمية بالرمز.
- أرقام الواتساب بيانات شخصية: اجعل الجدول خاصاً ولا تشاركه إلا مع من يحتاجه.
- الإشعارات تصل المتدربين بتأخير يصل إلى دقيقة.
- الدخول برقم الواتساب بمصادقة حقيقية غير مضمَّن هنا (يحتاج خدمة رسائل).
